Abstract

The DBC Ontology provides a formal, machine-interpretable representation of Controller Area Network (CAN) communication systems, capturing the semantics of messages, signals, electronic control units (ECUs), encoding schemes, and data logging processes. Built as an extension of the W3C SSN/SOSA standards and aligned with QUDT, it enables interoperable and semantically consistent modeling of low-level CAN bus data across transportation and cyber-physical system domains. The ontology supports dynamic signal decoding, ontology-based data access, and real-time as well as historical analytics when used within the CANDI framework (see here: https://github.com/paitools/DBCOntology and https://zenodo.org/records/17671851). The DBC Ontology is intended to facilitate reuse, extensibility, and integration into existing data engineering and analytics pipelines.
